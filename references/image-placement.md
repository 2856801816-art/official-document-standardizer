# 图片识别与插入规则

## 逐图识别

对每张图片记录主要人物或主体、活动或事件、场景地点、时间线索、可见文字、最适合支持的正文主题，以及裁切时必须保留的区域。不要仅依靠文件名判断图片内容；无法可靠识别时使用中性描述。

## 位置决策

1. 为每张图片选择语义最接近的段落或小节，通常插在该段之后、下一主题开始之前。
2. 同一事件有多张照片时分散在对应内容之间，避免连续堆叠；每个相关小节优先放一张代表性照片。
3. 图片不得打断标题与其首段，不得把落款、日期、附件说明拆开。
4. 正文少于 200 个汉字或字符且恰好只有一张照片时，必须把唯一照片放在全部正文之后，不得拆开正文句子。
5. 其他情况下禁止把全部照片放到文末。没有可靠匹配时先找最接近的小节；仍不确定则向用户说明，而不是机械堆放。

## 画面处理

- 最终画幅必须为 16:9，不拉伸。
- 优先围绕人物、标牌或主要动作裁切；裁切会删除关键信息时采用留白适配。
- 统一视觉宽度，通常不超过正文版心宽度。
- Word 中设置“上下型环绕”，水平居中；图片上下留出约 6–12 磅间距。
- 没有用户要求时不添加虚构图片说明。原稿已有图注则保留，并使图注与图片同页。

## 插图计划格式

```json
[
  {
    "path": "照片1.jpg",
    "after_contains": "会议研究了年度重点工作",
    "mode": "cover",
    "focus": "center"
  }
]
```

`after_contains` 必须是目标段落中唯一且稳定的短文本。`mode` 可为 `cover` 或 `contain`；`focus` 可为 `center`、`top` 或 `bottom`。
